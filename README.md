# learning-network
built myself a tiny corner of the internet because apparently my morning screen time needed a plot twist.

the idea is simple: instead of opening social media first thing in the morning, i get a random topic to research, a little time to explore it, and a place to keep track of what i've learned.

every time i learn something new, another tiny human joins my growing neural network. because apparently collecting random knowledge wasn't enough. i needed to make it visual too.

how it works

discover a random topic

spend a few minutes going down a research rabbit hole

write down something worth remembering

watch the little knowledge network grow
